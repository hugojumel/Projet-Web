# The Social Game

## Présentation

The Social Game est un site web qui encourage les interactions sociales grâce à un système de missions, de points et de niveaux.

L'objectif est de motiver les utilisateurs à rencontrer de nouvelles personnes, participer à des événements et renforcer leurs relations sociales.

## Fonctionnalités

- **Accueil** : présentation du jeu.
- **Tableau de bord** : missions hebdomadaires et suivi des points.
- **Événements** : inscription et désinscription aux événements.
- **Amis** : consultation de la liste d'amis.
- **Profil** : suivi de l'XP, des niveaux et des missions accomplies.

Les données sont sauvegardées localement grâce à `localStorage`.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript

## Installation

1. Télécharger le projet.
2. Ouvrir le dossier dans Visual Studio Code.
3. Lancer `accueil.html` avec Live Server.

## Organisation du projet

- `html/` : pages HTML
- `css/` : feuilles de style
- `js/` : scripts JavaScript
- `ressources/` : images et icônes
